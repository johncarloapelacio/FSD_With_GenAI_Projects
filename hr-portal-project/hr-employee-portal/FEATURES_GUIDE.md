# Features

- HR login provisioned through local environment configuration.
- One-time, private invitations for employee registration.
- HR employee directory and pending leave review (approve/deny once).
- Employee profile, leave application and own leave history.
- Server-enforced roles, scoped responses, salted password/invitation hashes and HttpOnly sessions.
- Request validation and atomic JSON persistence; corrupt stores are preserved and rejected.

See README.md for setup, exact checks and deployment limitations. There are no published demo credentials.

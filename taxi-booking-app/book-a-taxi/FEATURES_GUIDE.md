# Features

- Account registration/login using server sessions and password hashing.
- Validated booking draft, matching sample drivers and deterministic demo fares.
- Server-authoritative ownership, fare, ID and status.
- Private booking list and cancellation of upcoming confirmed rides.
- Profile update, password change with session rotation, and account deletion.
- Clear demo notice; contact form validates locally without claiming delivery.
- Keyboard selection of driver cards and an accessible navigation toggle.

See README.md for setup, verification and implementation limits. There are no shared demo credentials or live ride/payment integrations.

End-to-End Project Flow

1. Problem Statement

Build a GenAI-assisted testing approach for KYC and AML banking workflows.

2. Requirements

Chatbot, NLP, integration, KYC, AML, scalability, performance, and reporting requirements.

3. Synthetic Data

Seeded faker data creates realistic customers, screening fields, and AML transactions.

4. Jest Execution

Automated tests validate data quality, risk rules, coverage, and performance.

5. Evidence

RTM, test report, Agile plan, and GenAI write-up connect the work back to the rubric.
